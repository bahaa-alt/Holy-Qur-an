# Quranic Root & Word Research PWA

A free, open-source, account-less tool for researching Qur'anic roots, derived word forms and their every occurrence, with the Uthmani verse text and Saheeh International translation. Runs 100% client-side as a Next.js static export, installable as a PWA and fully usable offline.

**Status:** planning complete, implementation not started. The full, approved implementation plan (data sources, schemas, file tree, UI spec, PWA design, verification steps) is in [PLAN.md](./PLAN.md). Execute it top to bottom.
